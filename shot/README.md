# SHOT Lifestyle & Coffee · concept site (Dolcessi)

Live: https://demo.dolcessi.com/shot/ · noindex · concept, not the official site.

## What's in it
- **Hero** – espresso stage, giant Bodoni "SHOT" baked into the WebGL backdrop so the clear can refracts it; floating Iced Matcha can, mouse tilt.
- **The ritual** (pinned, 760vh) – an empty slim clear can is lowered in, four pours stack Strawberry Cheesecake Matcha layer by layer (live ml counter), ice drops in, the aluminium lid descends and seams on, condensation beads, the can is shaken.
- **Signatures** (pinned, 820vh) – one can morphs through 7 drinks; background tint, watermark word and photo planes (wipe reveals, depth parallax) change per drink.
- Statement (words light up), horizontal craft gallery, full tabbed menu with hover photo peek, brand collabs + marquee, shop, two cities (live Amsterdam hours, Rotterdam soon), footer.
- EN/NL, mobile Order/Directions bar, reduced-motion, `?test` mode (`window.__step()`).

## Files
can.js (can geometry, liquid shader, print, lid, ice) · world.js (stage, backdrop, stream, photo planes) · app.js (content, choreography, scroll) · style.css · img/photo (Unsplash, credits.json) · card.pdf + qr.png (walk-in card).
